# yanzien 留言板 · D1 网页点按钮教程

> 不需要记命令。全程在 Cloudflare 网页控制台里点按钮完成。
> 配套代码已写好：`worker.js`（D1 版）+ `schema.sql` + `wrangler.toml`。

---

## 第一步：创建 D1 数据库

1. 登录 [dash.cloudflare.com](https://dash.cloudflare.com)，进入你的域名/账户。
2. 看左侧菜单，找到 **「存储和数据库」** → **「D1 SQLite 数据库」**，点击。
3. 点右上角的 **「创建数据库」** 按钮。
4. 在弹窗里：
   - **数据库名称**：输入 `yanzien-guestbook`
   - 点 **「创建」**
5. 创建成功后，会跳转到数据库详情页。看到地址栏里有一串 ID，或者页面上有 **「数据库 ID」** 字段。复制这串 ID（形如 `xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`）。

> 💡 这串 ID 后面要填到 Worker 里。

---

## 第二步：给数据库建表

1. 在刚刚创建的 `yanzien-guestbook` 数据库详情页，找到页面上方的 **「查询」**（英文是 **Query**）标签页，点击。
2. 你会看到一个 SQL 输入框。
3. 打开本文件夹里的 `schema.sql`，把里面的内容全部复制：
   ```sql
   CREATE TABLE IF NOT EXISTS messages (
     id          INTEGER PRIMARY KEY AUTOINCREMENT,
     name        TEXT    NOT NULL,
     message     TEXT    NOT NULL,
     status      TEXT    NOT NULL DEFAULT 'pending',
     created_at  INTEGER NOT NULL,
     ip          TEXT
   );

   CREATE INDEX IF NOT EXISTS idx_messages_status_time ON messages(status, created_at DESC);
   CREATE INDEX IF NOT EXISTS idx_messages_time ON messages(created_at DESC);
   ```
4. 把复制的内容粘贴进 SQL 输入框。
5. 点 **「执行」**（英文 **Run**）按钮。
6. 看到成功提示即可。

---

## 第三步：创建 Cloudflare Worker

1. 左侧菜单点 **「Workers and Pages」**。
2. 点 **「创建」** 按钮（或 **Create application**）。
3. 选择 **「创建 Worker」**（英文 **Create Worker**）。
4. 给 Worker 起个名字，比如 `yanzien-guestbook`，然后点 **「部署」**（**Deploy**）。
5. 部署成功后，会跳转到 Worker 的编辑页。

---

## 第四步：把 D1 数据库绑定到 Worker

1. 在 Worker 详情页，点顶部 **「设置」**（**Settings**）标签。
2. 左侧选 **「绑定」**（**Bindings**）。
3. 点 **「添加」** 按钮，选择 **「D1 数据库」**（**D1 database**）。
4. 在弹出的表单里：
   - **变量名称**：填 `DB`（必须大写，代码里用的就是这个名字）
   - **数据库**：选择你刚才创建的 `yanzien-guestbook`
5. 点 **「保存」**（**Save**）。

---

## 第五步：粘贴 Worker 代码

1. 回到 Worker 详情页顶部，点 **「编辑代码」**（**Edit code**）按钮，进入在线编辑器。
2. 左侧文件列表里应该有个 `worker.js`，点击它。
3. 把编辑器里原来的示例代码**全部删除**。
4. 打开本文件夹里的 `worker.js`，全部复制，粘贴进去。
5. 点右上角的 **「保存并部署」**（**Save and deploy**）。

> 部署成功后，页面上方会显示 Worker 的访问地址，比如 `https://yanzien-guestbook.your-account.workers.dev`。复制这个地址，后面要填到后台。

---

## 第六步：设置机密变量（Secrets）

1. 在 Worker 详情页，点顶部 **「设置」**（**Settings**）。
2. 左侧选 **「变量」**（**Variables**）。
3. 点 **「添加」** 按钮，选择 **「加密」**（**Encrypt**）类型。
4. 添加第一条：
   - **变量名称**：`ADMIN_TOKEN`
   - **值**：你自己定一串随机字符，比如 `yanzien2026abc123`（越乱越好，记下来，后台管理要用）
5. 点 **「保存」**。
6. 再点 **「添加」**，添加第二条（Turnstile 验证码私钥）：
   - **变量名称**：`TURNSTILE_SECRET`
   - **值**：从第七步里复制过来的 Secret Key

> 如果你第七步还没做，可以先把 `ADMIN_TOKEN` 加上，Turnstile 的等第七步做完再来补。

---

## 第七步：开启 Turnstile 验证码

1. 回到 Cloudflare 控制台左侧菜单，找到 **「Turnstile」**（在「安全」或「更多」下面，直接点）。
2. 点 **「手动添加小部件」**（新版中文界面；老版叫 **Add site**）。
3. 填写：
   - **站点名称**：`yanzien-home`
   - **域名**：`yanzien.github.io`
   - **小组件模式**：选 **「受管」**（**Managed**）即可
4. 点 **「创建」**。
5. 创建成功后，页面会显示两个 key：
   - **Site Key**：填到后台「留言方式」里的「Turnstile 站点密钥」
   - **Secret Key**：填到第六步的 `TURNSTILE_SECRET` 里

---

## 第八步：配置跨域（CORS）

1. 回到 Worker 详情页，点 **「设置」** → **「变量」**。
2. 点 **「添加」**，选择 **「纯文本」**（**Text**）类型：
   - **变量名称**：`ALLOWED_ORIGIN`
   - **值**：`https://yanzien.github.io`
3. 点 **「保存」**。

> 如果你想本地预览时也能测试留言，可以把值改成 `*`（允许所有来源）。等正式发布后再改回 `https://yanzien.github.io`。

---

## 第九步：到后台把 Worker 接进网站

1. 打开你的网站后台：`https://yanzien.github.io/home/admin.html`
2. 先按提示连接 GitHub（用户名/仓库/分支/PAT），让后台能读写 `data/content.json`。
3. 连接成功后，点左侧 **「设置」** → **「站点 / 云端」**。
4. 找到 **「留言方式」** 区域：
   - **模式**：选 **Cloudflare Workers + D1**
   - **Worker 地址**：粘贴第五步复制的 Worker URL
   - **Turnstile 站点密钥**：粘贴第七步的 Site Key
5. 点 **「保存留言配置」**。保存后，配置会自动提交回 GitHub 仓库。

---

## 第十步：管理留言

1. 后台左侧点 **「留言管理」**。
2. 第一次打开会提示输入 **ADMIN_TOKEN**，就填第六步你设置的那串随机字符。
3. 之后就能看到所有留言：
   - 新留言默认是 **待审核（pending）**，前台不显示
   - 点 **通过**：前台就能看到了
   - 点 **隐藏**：前台不再显示
   - 点 **删除**：彻底删掉

---

## 完成 ✅

现在访客可以在前台直接留言（不用登录 GitHub），新留言会先进入待审核，你在后台点一下「通过」就会显示出来。
