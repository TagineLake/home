1创建 D1 数据库

  1. 登录 dash.cloudflare.com。
  2. 左侧菜单找 存储和数据库 → D1 SQLite 数据库，点进去。
  3. 点右上角 创建数据库 按钮。
  4. 弹窗里：数据库名称 填 yanzien-guestbook，点 创建。
  5. 创建后跳到数据库详情页。找到页面上的 数据库 ID（一串带横杠的字符），先不用复制，后面在 Worker 里选这个库就行。

2给数据库建表

  1. 在 yanzien-guestbook 数据库详情页，点上方的 查询（Query）标签。
  2. 看到一个 SQL 输入框。把下面这段全部复制粘进去：
CREATE TABLE IF NOT EXISTS messages (
  id          INTEGER PRIMARY KEY AUTOINCREMENT,
  name        TEXT    NOT NULL,
  message     TEXT    NOT NULL,
  status      TEXT    NOT NULL DEFAULT 'pending',
  created_at  INTEGER NOT NULL,
  ip          TEXT
);

CREATE INDEX IF NOT EXISTS idx_messages_status_time ON messages(status, created_at DESC);
CREATE INDEX IF NOT EXISTS idx_messages_time ON messages(created_at DESC);
  1. 点 执行（Run）按钮，看到成功提示即可。

3创建 Cloudflare Worker

  1. 左侧菜单点 Workers and Pages。
  2. 点 创建（或 Create application → Create Worker）。
  3. 名字填 yanzien-guestbook，点 部署（Deploy）。
  4. 部署完跳到 Worker 详情页。

4把 D1 绑定到 Worker

  1. Worker 详情页顶部点 设置（Settings）。
  2. 左侧选 绑定（Bindings）。
  3. 点 添加 → 选 D1 数据库。
  4. 表单里：
    • 变量名称 填 DB（必须大写，代码认这个名字）
    • 数据库 选 yanzien-guestbook
  5. 点 保存。

5粘贴 Worker 代码

  1. Worker 详情页顶部点 编辑代码（Edit code），进在线编辑器。
  2. 左侧文件列表点 worker.js。
  3. 把里面原有示例代码全部删掉。
  4. 打开本站文件 /cloudflare/worker.js，全选复制，粘贴进编辑器。
  5. 点右上角 保存并部署（Save and deploy）。
部署成功后页面上方会显示 Worker 访问地址，形如 https://yanzien-guestbook.你的账号.workers.dev。复制这个地址，第 10 步要填进后台。

6设置机密变量 ADMIN_TOKEN

  1. Worker 详情页点 设置 → 左侧 变量（Variables）。
  2. 点 添加 → 选类型 加密（Encrypt）。
  3. 填：
    • 变量名称：ADMIN_TOKEN
    • 值：你自己定一串随机字符，例如 yanzien2026abc123（越乱越好，记下来，后台审核留言要填）
  4. 点 保存。

7开启 Turnstile 验证码

  1. 左侧菜单找 Turnstile（在「安全」分组下，直接点）。
  2. 点 手动添加小部件（新版中文界面；老版叫 Add site）。
  3. 填：
    • 站点名称：yanzien-home
    • 域名：yanzien.github.io
    • 小组件模式：选 受管（Managed）
  4. 点 创建。
  5. 创建后页面显示两个 key：
    • Site Key（站点密钥）→ 第 10 步填进后台
    • Secret Key（私钥）→ 下一步填进 Worker

8补填 Turnstile Secret

  1. 回到 Worker 详情页 → 设置 → 变量。
  2. 再点 添加 → 类型 加密：
    • 变量名称：TURNSTILE_SECRET
    • 值：粘上一步的 Secret Key
  3. 点 保存。

9配置跨域 ALLOWED_ORIGIN

  1. 还在 Worker 设置 → 变量 页。
  2. 点 添加 → 类型选 纯文本（Text）：
    • 变量名称：ALLOWED_ORIGIN
    • 值：https://yanzien.github.io
  3. 点 保存。
提示：本地预览测试时把它改成 *（允许所有来源），正式发布再改回 https://yanzien.github.io。

10到后台接入 Worker

  1. 打开你的网站后台：https://yanzien.github.io/home/admin.html（本地预览就用 /admin.html）。
  2. 先按提示连接 GitHub（用户名 / 仓库名 home / 分支 main / PAT），让后台能读写 data/content.json。
  3. 连上后点左侧 设置 → 找 留言方式 区域：
    • 模式：选 Cloudflare Workers + D1
    • Worker 地址：粘第 5 步复制的 Worker URL
    • Turnstile 站点密钥：粘第 7 步的 Site Key
  4. 点 保存留言配置。保存后配置会自动提交回 GitHub 仓库。

11管理留言

  1. 后台左侧点 留言管理。
  2. 第一次会提示输入 ADMIN_TOKEN，填第 6 步你设的那串随机字符。
  3. 之后能看到所有留言：
    • 新留言默认 待审核（pending），前台不显示
    • 点 通过：前台就能看到
    • 点 隐藏：前台不再显示
    • 点 删除：彻底删掉

完成 ✅

现在访客能在前台直接留言（不用登录 GitHub），新留言先进待审核，你在后台点「通过」就显示出来。
